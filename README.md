# shares

公开分享站：放**可以给别人看**的 HTML 成品。

- 网址：`https://wuyan1599-dot.github.io/shares/`
- 文件推送后 1-2 分钟自动生效，无需构建
- 私密资料放 `my-assets` 私有仓库，不要放这里

## 怎么分享

把 HTML 放进本目录 → 推送 → 取链接：

```
https://wuyan1599-dot.github.io/shares/<文件路径>
```

例：`workbuddy-test.html` → `https://wuyan1599-dot.github.io/shares/workbuddy-test.html`
